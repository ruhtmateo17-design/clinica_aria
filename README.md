# Clínica Arias – Sistema de Gestión Integral

Sitio web estático (HTML + Tailwind CDN) desarrollado para la clase de Tecnología Educativa (MTEMA).

- `index.html` – Portal institucional / atención al paciente
- `login.html` – Inicio de sesión y control de usuarios
- `panel.html` – Panel principal
- `enfermeria.html`, `emergencias.html`, `pacientes.html`, `laboratorio.html`, `caja.html`, `reportes.html`, `relevo.html` – Módulos del sistema
